# ex3ittt.github.io

Сайт-портфолио: https://ex3ittt.github.io

Список проектов лежит в [`src/data/projects.ts`](src/data/projects.ts), скриншоты в
`public/shots/`. Чтобы добавить проект, допиши его в массив. После пуша GitHub
Actions соберёт сайт и выложит его.

```bash
npm install
npm run dev     # http://localhost:4321
```

Astro. За именем по лабиринту сами ползают змейки, по одной на каждый проект и в его цвете.
Каждая выбирает случайную точку, ищет к ней дорогу через A* (как в «Поиске пути») и ползёт туда.
Курсор подсвечивает лабиринт вокруг себя, а при наведении на полосу проектов выделяется змейка
этого проекта (`src/scripts/field.ts`). Анимация идёт, только пока шапку видно; при настройке
«уменьшить движение» рисуется один неподвижный кадр.
