# ex3ittt.github.io

Сайт-портфолио: https://ex3ittt.github.io

Список проектов лежит в [`src/data/projects.ts`](src/data/projects.ts), скриншоты в
`public/shots/`. Чтобы добавить проект, допиши его в массив. После пуша GitHub
Actions соберёт сайт и выложит его.

```bash
npm install
npm run dev     # http://localhost:4321
```

Astro. За именем на главной работает A* из проекта «Поиск пути»: он ищет дорогу
в лабиринте к курсору, а каждый новый путь рисуется цветом следующего проекта
(`src/scripts/field.ts`). Анимация идёт, только пока шапку видно; при настройке
«уменьшить движение» рисуется один неподвижный путь.
