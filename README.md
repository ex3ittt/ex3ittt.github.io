# ex3ittt.github.io

Сайт-портфолио: https://ex3ittt.github.io

Список проектов лежит в [`src/data/projects.ts`](src/data/projects.ts), скриншоты в
`public/shots/`. Чтобы добавить проект, допиши его в массив. После пуша GitHub
Actions соберёт сайт и выложит его.

```bash
npm install
npm run dev     # http://localhost:4321
```
